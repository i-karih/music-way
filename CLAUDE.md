# Music Way — Monorepo

## Структура

```
/music-way
  /apps/web        ← Nuxt приложение (@music-way/web)
  /packages/ui     ← UI библиотека (@music-way/ui)
```

## Команды

```bash
pnpm dev        # запуск
pnpm build      # сборка
pnpm lint       # линтинг
```
